# Invoice Generator Frontend Web App

React 19 & Vite single-page application (SPA) for the Invoice Generator & Management System.

For full project context, API mapping, role authorization matrix, and environment setup, refer to the root [README.md](../README.md).

## Quick Start

```bash
# Install dependencies
npm install

# Run in Development Mode
npm run dev

# Build for Production
npm run build

# Preview Production Build
npm run preview
```
